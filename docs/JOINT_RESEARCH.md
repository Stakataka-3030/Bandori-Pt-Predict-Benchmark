# T1000 / T1500 联合预测研究（2026-10-28）

**结论：保留可运行候选，暂不替换默认模型。** 联合比例先验可以消除部分独立预测交叉，新的 Rui 家族权重也改善了候选选择期误差；但冻结后在 326 的 T1500 出现反例。解除输出重合，不等于提高预测准确率。

## 原因与候选

v0.3.20 早期模型把每档当前 PT 分别除以历史归一化进度，得到独立的终值预测。四档使用同一批历史活动，也不保证独立缩放后的 T1500 小于 T1000。发布层随后将 T1500 截至固定的 T1000：两条相等的公开线可能来自原始交叉，而非模型认为真实档差为零。

本轮分别研究了联合比例/档差、联合历史轨迹、回归、增长率外推、残差校准与顺序权重。开发过程含多个探索版本，其开发期成绩不构成独立验证。进入后续比较的仅两版冻结候选：

1. `joint`：保留已有原始预测，以已完成同制度活动的 `log(T1500 / T1000)` 中位数和 MAD 学习终值比例先验。原始交叉时回到先验；正常原始比例只有超出稳健带宽时才收缩，临近结束收缩减弱。冻结版本保留 T1000 锚点，允许 T1500 上下调整。没有人为指定固定档差。
2. `joint_rui`：Mashiro 同上；Rui 改为对历史活动家族分配权重，按可见的跨档相对增长更新，限制单步惩罚并保留先验质量。历史曲线在后续报点可用时加入，避免开场阶段缺样永久排除；按加权顺序统计量中点插值得到平滑中位数，再应用同一联合比例层。

这里的家族数是实际历史样本数。研究工具**只提供点预测**，不把家族权重冒充 50 个独立活动，不生成 Aoi 成员或概率区间，也不改写旧成员分位。

## 评测边界

- 开发：315、317、318、319、320、321，沿用用户允许的独立研究划分。
- 候选选择：322、323、324、325。对两版候选各比较一次，锁定 `joint_rui` 后再看 326。
- 本轮一次性验证：326。它曾在此前的监控讨论中出现，因此这是**回顾性研究的冻结候选验证**，不称为全新盲测。
- 327 仍在进行，没有结算标签；仅以已经冻结的可见 tracker 前缀作离线运行示例，不参与误差选型。
- 六个时点：开场后 3 / 24 / 48 小时，截活前 72 / 24 / 6 小时。每场先平均同一批档位和时点的绝对 PT 误差，再按活动等权平均。T1000/T1500 单独报告，绝不以所有档位合计改善掩盖单档退化。
- 训练按国服实际开场时刻排序，只使用目标开场前已经结束的同制度活动。预测只读当前起报时可见的 tracker；迟到的修订和迟到的终值不提前使用。
- 325、326 的开场 3 小时缺少可用四档历史，比较中分别保留缺失；两模式合计每场缺 8 个案例，不补零。候选选择共有 4 个独立活动，184 个有效模式×档位×时点案例；验证只有 1 个活动、40 个有效案例。
- 这是与 **v0.3.20 相同逻辑模式**的比较，并非相对 BSDO、TSYC、MYCX-A 的强基准结果，也不是原 CN-Core 的新 PointScore。

## 独立复算结果

单位为万 PT；以下均为事件等权原始 MAE，越低越好。完整聚合数值见 [JSON](joint_research_20261028.json)。

| 阶段 | 模式/档位 | v0.3.20 | 冻结候选 | 变化 |
|---|---|---:|---:|---:|
| 322—325 选择 | Rui / T1000 | 73.84 | 64.52 | 降低 12.6% |
| 同上 | Rui / T1500 | 64.18 | 57.53 | 降低 10.4% |
| 同上 | Rui / 两档合计 | 69.01 | 61.03 | 降低 11.6% |
| 同上 | Mashiro / 两档合计 | 75.68 | 76.65 | 增加 1.3% |
| 326 验证 | Rui / T1000 | 15.60 | 9.91 | 降低 36.5% |
| 同上 | Rui / T1500 | 8.58 | 28.43 | **增加 231.5%** |
| 同上 | Mashiro / T1500 | 18.20 | 10.33 | 降低 43.2% |
| 同上 | 两模式 / T1500 | 13.39 | 19.38 | **增加 44.8%** |
| 同上 | 两模式 / 所有四档 | 13.30 | 11.40 | 降低 14.3% |

最后两行说明为何不把它升级为默认算法：总误差下降与重点档位退步可以同时发生。不能在看到 326 后挑选其中表现好的模式重新宣称通过；也不再用 326 调整此次候选参数。现有数据不足以证明稳定的 30% 原始误差降幅，更不能证明所有未来模型都做不到。

## 运行与验证

[离线实现](../examples/local_app/joint_research.py) 是标准库研究入口，默认应用、baseline registry、每日监控版本和已冻结报文均不变。

```powershell
python examples/local_app/joint_research.py `
  --panel <起报时四档面板.json> `
  --state <该活动之前的衍生状态.json> `
  --completed <已完成历史bundle.json> `
  --mode rui `
  --out <新的研究输出.json>
```

`--completed` 使用 `reference_events` 列表；仅历史活动可含最终标签。`--panel` 不需要且不读取目标最终标签。状态训练截止时间必须早于目标开场；目标、未完成活动、重复历史活动、未发布的历史终值会被拒绝。输出以独占方式创建，不覆盖冻结文件，不联网、不训练、不改写状态。`research_only` 和 `point_forecast_only` 明确标识该接口不代表已发布报文或概率预报。

移植后的实现与冻结候选在 322—326 的 224 个可用点预测上核对，最大数值差为 `4.66e-10 PT`；该核对只检查实现一致性，没有更换冻结参数或再选候选。新增测试覆盖未来/迟到数据、目标标签污染、状态时间边界、同制度隔离、排名顺序、数据不变性和缺少证据时不伪造档差。仓库现有 Linux / Windows、Python 3.11 / 3.13 CI 会运行这些测试。

后续需要新的时间外活动检验联合结构与顺序权重，尤其要报告 T1500 的独立结果。拟合样本的同制度划分、历史终值比例与 50 条成员的有效样本数需要分别保留，不能把输出层 Clamp 当作已解决模型偏差的证据。
