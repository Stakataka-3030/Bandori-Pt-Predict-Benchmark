# Nanami：可选的四档联合点预测

Nanami 同时保留 T500、T1000、T1500、T2000 的独立预测信号，并按当前奖励类别学习“剩余增长预测误差”。T1000 可以随联合估计调整，不再仅将 T1500 截断到固定的 T1000 下方。

新制度四档都有奖励；500、1500 的相对吸引力较强。模型在**同一制度、同一预测时距**内，对每个已完成活动的同类别误差先取平均，再在活动间取中位数，并以 n/(n+4) 收缩。n 是独立活动数。类别没有数值奖励强度；旧 T1000 不直接等同于新 T1500。最后通过带当前档线下界的四档联合加权保序求解得到终值。

## 使用

Nanami 保留内部 `topology` 模式键和 `topology_t` 状态格式，API 同时接受 `nanami` 别名；预测数值没有因改名改变。现有 Mashiro 默认、Rui 和原状态文件继续可用。T 是独立可选点预测，未提供经过验证的概率区间或未来增长轨迹，不借用 Aoi/Rui 成员区间。图上虚线只是当前值到终值的显示连线。

从按真实开始时间排序的本地历史资料导出含 T 的衍生状态：

```bash
python examples/local_app/export_state.py historical-dataset.json --with-topology --out topology-seed.json
python examples/local_app/app.py --seed topology-seed.json --state topology-model/tsukushi-state.json
```

Windows PowerShell 使用相同参数；项目根目录需要在 Python 导入路径中，例如先执行 `$env:PYTHONPATH="."`。历史输入可以是含 `reference_events` 的可信 benchmark bundle，也可以是含 `events` 的规范化 dataset。只输入**已结束活动**；不得把目标或未来活动加入状态。

**请使用新的独立 `--state` 目录。** 已有目录中的 immutable seed 与训练账本不会被后来传入的 `--seed` 替换。不要覆盖原模型的 seed、状态或训练账本。含 T 的新目录会在已有自动同步流程中，先用旧状态预测新活动历史截点，再加入该活动的衍生残差。旧状态无 T 扩展时按钮禁用，不静默冒充已校准的 T。

在页面选 `Nanami` 后正常起报。支持国服新制度、完整四档、每档最近可见数据不超过 3 小时。活动结束前 72/48/24/12/6 小时是已评估截点；6–72 小时内的其他时刻使用最近时距近似，少于 6 小时显式标记超出已评估范围，超过 72 小时不提供 T。旧模式继续支持其原有范围。状态若已包含目标活动，或其训练观察当时尚未可用，T 拒绝回放。

## 已知表现与接受标准变更

基线为 0.3.17 的 Kaori 加原有档序约束。8 场已被研究过程看过的现代活动（317–324），38 个共同可用截点、每模型 152 个档位预测。这些是回顾性开发资料，不是盲测或保存于当时的实时预测。

| 指标 | 相对基线 |
|---|---:|
| 四档原始 PT 事件平均 MAE | 降低 11.5364% |
| T1000/T1500 原始 PT 平均 MAE | 降低 15.7533% |
| 固定尺度标准化四档误差 | 降低 7.8106% |
| T500 MAE | 降低 9.1411% |
| T1000 MAE | 降低 4.1715% |
| T1500 MAE | 降低 24.7391% |
| T2000 MAE | **增加 2.0011793864%** |

标准化误差 7/8 场改善，原始四档 MAE 6/8 场改善；逐场留一后的整体改善方向保持一致。T 优于自身逐档校准及三个固定分组对照，但这只提供探索性支持，不证明奖励吸引力决定误差。

原预注册门槛仍然**未通过**：标准化改善不足 10%，T2000 回退略超过 2%，98.75% 活动级配对重采样区间跨零（标准化差 [-0.00412014, 0.07305233]；双档 PT 差 [-1368.82, 107080.57]）。用户在看到结果后明确改为“有比较明显的改善就行”，因此接入可选候选。没有重写旧门槛为通过，也不声称统计显著或未来有效。原冻结研究与 G/T 后续验证协议保持原样。

T2000 的竞争深度可能与其他档不同；“认真竞争人数少于 2000”是待验证机制，现有档线不能识别该人数。该版本没有据此增加阈值、人数推断或事后专用修正。

## 验证边界

本地导出状态的 T 预测与原研究 152 个共同案例逐值一致（最大绝对差 0）。测试覆盖导出/增量重建、全部五个时距、目标与未来状态拒绝、修订可用时间、原模式兼容与点预测展示。派生状态只存必要校准量及规范化轨迹，不含原始 tracker 档案；真实历史输入不进入 Git。
