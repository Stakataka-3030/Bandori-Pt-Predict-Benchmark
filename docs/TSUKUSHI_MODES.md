# Tsukushi 本地预测模式

Tsukushi 的服务层仍是 **Kaori 主报线**和 **Aoi 成员线**；**Mashiro / Rui** 是可切换的预测逻辑，在图的角标中显示，不取代 Kaori / Aoi 的名称或模型 ID。

应用默认选择 **Mashiro**。它沿用 v0.3.13 的 Kaori 控制线与 Aoi 成员线计算；每次刷新只使用当前可见的档线，原有模型参数、训练状态和 baseline registry 不变。

**Rui** 是独立的顺序成员模式。它从活动开场满三小时后的第一个可用报点建立固定成员集；按三小时节奏回放历史报点，截活前 24 小时改按一小时节奏，并在当前起报时刻额外计算一次。每一步只读该时刻已经可见的四档 tracker，先将上一报成员轨迹与实际档线比较，再以稳健损失更新权重。保留最低权重，不硬删成员；随后用当前实况重新锚定同一批成员的未来轨迹。Rui 主报取加权成员中位数。

回放每次都从头计算，不在两次应用运行之间保存成员权重。训练状态只由已完成活动更新；当前活动的最终值不会进入预测输入。若开场阶段可用历史轨迹不足三场，Rui 明确报错，不返回伪造的预测。

两种模式仍显示四档成员 10%／90% 分位；它们尚不是概率覆盖率校准后的区间。截活前 24 小时的一小时线性投影是额外参考线，截活前 3 小时的优先参考提示在两种模式下都保留。Rui 是新增候选，不能仅凭单场回放结果宣称它比 Mashiro 更准。

## 对外档位顺序

v0.3.15 在模型预测**之后**约束展示值为 `T500 ≥ T1000 ≥ T1500 ≥ T2000`。正常情况下保留 T500／T1000／T2000 的原值，仅把辅助 T1500 限制在 T1000 与 T2000 之间；若三个主档自身倒序，才对它们做最小平方距离的单调投影。未来主报线、50 条成员线、终值分位及可用的一小时投影线使用同一约束，历史实际档线不改。

报表 JSON 的 `raw_control`、`raw_control_paths`、`raw_member_terminals`、`raw_member_quantiles` 和 `raw_linear1h` 保存校正前结果；`rank_order_adjustment` 标明哪些对外曲线被调整。这是输出层一致性处理，不代表模型本身重新拟合，也不应把校正后的回放当成当时实际发布的预测。
