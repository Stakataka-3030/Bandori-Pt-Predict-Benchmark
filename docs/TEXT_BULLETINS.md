# 文本报文

“生成文本报文”只取一次所选来源的四档 tracker，在同一真实起报时刻和同一训练状态下运行 Mashiro 与 Rui。两种格式均输出经档位顺序校正后的 Kaori 终值与 Aoi 10%／90% 分位，不使用额外的一小时线性投影替代 Kaori。

数值报文使用 `STSTSTST` / `EDEDEDED` 包围，期数与服务器代码直接拼接，例如 `325CN`。UTC 时间格式为 `YYYYMMDDHH`；时间按四舍五入到整小时（半小时进位），时效取显示的两个整点之差，因此不包含分钟。可读报文使用相同整点，按北京时间显示。数值四舍五入到整数 PT，数字不含千位分隔；成员分位以 `低值|高值` 分隔。

数值段按 `MASKAORI`、`MASAOI`、`RUIKAORI`、`RUIAOI` 排列，每段的档位顺序为 T500、T1000、T1500、T2000。可读报文的活动名称优先中文，缺失时回退日文；服务器显示国服。

若任一逻辑的主报、成员轨迹或投影触发 T1500 校正，数值报文在结尾标记前加入单独的 `CLAMPED` 行，可读报文末尾加入 `模型数值已Clamp`。

预览窗口可切换两种格式、复制全文或下载 UTF-8 TXT；两份文本和包含双逻辑快照的 JSON 也会保存在本机 reports 目录。任一逻辑无法出报时整体报错，不拼接不同起报时刻的结果，也不输出空值替代预测。
