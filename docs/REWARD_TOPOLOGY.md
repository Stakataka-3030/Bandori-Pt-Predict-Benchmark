# CN奖励拓扑与兼容特征

根据2026-10-01的用户纠正，旧制度在本项目跟踪的四个名次中只有T1000一个独立奖励档；新制度在T500、T1000、T1500、T2000均设置独立奖励档，其中T500和T1500的奖励吸引力相对更强。这里描述的是奖励分档边界，不是说更高排名的玩家完全拿不到奖励。

`voice1000`和`voice500_1500`继续作为历史时代标识符，以保持数据兼容。后者不能被解释为新制度只有500和1500有奖励。具体奖励物品、价值和数值强度未由这些事实确定，代码不会编造。

## 版本明确的接口

- `reward_topology(task)`返回`cn-reward-topology-v2`、用户提供的来源、已知状态、奖励边界和吸引力类别
- `reward_feature_dict(task)`是完整拓扑v2的数值指示特征；新制度四档的`reward_boundary`均为1，500/1500另有相对较强类别，1000/2000属于其他有奖励类别
- 旧制度T1000的独立奖励档是单独类别，不假设其吸引力等于现代任何类别
- 其他服务器、未知时代和用户没有说明的名次保持未知，不能把指示值0理解成已证实没有奖励

0.3.16及以前的通用`reward_feature_dict`实际上只描述旧T1000和新T500/T1500的几何关系，名称过宽。其原始运算完整保存在`legacy_reward_feature_dict`中，明确标记为`legacy-reward-geometry-v1`。已有CARE-S和CARE-S2继续显式调用这个兼容接口，因此历史评分和预测可复现。新CARE候选若采用v2，需要独立的模型版本和评测，不能把新特征偷偷放进旧基线。

Mashiro/Kaori的尾速与倍率组合不调用这两个特征函数，因此本次接口和说明纠正本身不会改变默认预测。倍率模型的0.92仍作为先前经验选择的系数保留，不能被解释为T1000没有奖励，也不是奖励价值的数值估计。

## 对既有研究解释的更正

将新制度T1000/T2000描述为“无奖励档”，或把500/1500当成新制度唯一奖励位置的解释不成立。此前报告中“只修正奖励档”的表述若指仅调整500/1500，应当明确更正为“只调整相对吸引力较强的两个奖励档”。原始误差测量仍然有效，但基于无奖励假设的机制归因应撤回。

完整四档拓扑提供了新的分类信息，可以检验同一时代内按吸引力类别共享残差是否有效；这只是待验证假设。相对吸引力相似并不自动意味着基础模型误差相同，也不授权把旧T1000与新T1500当成等价奖励直接混合训练。
